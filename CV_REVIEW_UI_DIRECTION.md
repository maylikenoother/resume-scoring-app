# CV Review Product Interface — Clear Review

The application will use a polished blue product system built around a calm white canvas, cobalt blue primary actions, blue-grey support surfaces, and high-contrast slate text. The user journey should explain what happens next, validate inputs inline, and return helpful, non-technical feedback for failed login or registration requests.

Account screens use a contained, responsive layout with a compact brand lock-up, a practical progress note, password visibility control, and clear recovery navigation. The dashboard should lead with the current review status, then reveal the next useful action. Components must be typed, small in responsibility, accessible by keyboard, and documented with the design reminder: **Clear Review — polished blue product interface, calm hierarchy, practical feedback.**
